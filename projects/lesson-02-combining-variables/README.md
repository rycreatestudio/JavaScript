# Lesson 2 Project — Mission Briefing

**Time:** ~20–40 minutes  
**Pairs with:** `lesson-2-combining-variables.js`

Build mission briefing lines using template literals and combined variables. The card stays on placeholders until you finish the final display step.

## How to run

1. Open `index.html` in your browser.
2. Open the developer console (`Cmd + Option + J` on Mac).
3. Edit `script.js` and refresh the page after each step.

## Concepts used in YOUR exercises

- `let` and `const`
- strings, numbers, booleans
- reassignment
- `console.log()`
- combining strings with `+`
- template literals with `` ` `` and `${variable}`

## Files

| File        | Purpose                          |
|-------------|----------------------------------|
| `index.html` | The mission briefing card       |
| `script.js`  | Your exercises (start here)     |

## Where to begin

Open **`script.js`** and start at **Step 1**.

Work through each step in order. Do not skip ahead to the display step — build your strings first, log them, then call the helper at the end.

## Helper code

Anything marked `HELPER CODE — DO NOT MODIFY YET` in `script.js` is provided for you. You do not need to understand it yet.

## When you're done

After Step 11, refresh the browser. All four lines on the card should show your sentences instead of the placeholder text.
