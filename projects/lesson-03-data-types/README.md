# Lesson 3 Project — Save File Inspector

**Time:** ~20–40 minutes  
**Pairs with:** `lesson-3-data-types.js`

Inspect game save data like a QA engineer — check values, run `typeof`, and spot type mismatches. The inspector panel stays on placeholders until you finish the final display step.

## How to run

1. Open `index.html` in your browser.
2. Open the developer console (`Cmd + Option + J` on Mac).
3. Edit `script.js` and refresh the page after each step.

## Concepts used in YOUR exercises

- `let` and `const`
- strings, numbers, booleans
- `undefined` and `null`
- `typeof`
- comparing `"100"` vs `100` and `"true"` vs `true`
- template literals
- reassignment
- `console.log()`

## Files

| File         | Purpose                       |
|--------------|-------------------------------|
| `index.html` | Save File Inspector panel     |
| `script.js`  | Your exercises (start here)   |

## Where to begin

Open **`script.js`** and start at **Step 1**.

Work through each step in order. Use the console to verify your `typeof` results as you go. Call the helper only at **Step 13**.

## Helper code

Anything marked `HELPER CODE — DO NOT MODIFY YET` in `script.js` is provided for you. You do not need to understand it yet.

## When you're done

After Step 13, refresh the browser. All nine rows on the inspector should show your data instead of the placeholder text.
